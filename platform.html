Know what you're looking at.

A lease, an email and a summary are different kinds of evidence. Each has a source, a date and a reason it matters.

Make the trail visible.

If a system draws a conclusion, the person using it should be able to see the material behind it.

An incomplete file should be called incomplete. Guesswork shouldn't be dressed up as a confident answer.
